ARNAV SARAF ENGINEERING PORTFOLIO

Open index.html in your browser. Keep all files together.

PAGE ORDER
About me, Projects, Experience. All sections appear on one scrolling page.

EDIT PROJECTS AND EXPERIENCE
Open content.js in a text editor. The projects and experiences lists contain
one labelled block per entry. Save and refresh your browser after editing.

ADD AN ENTRY
Copy an entire { ... }, block in the appropriate list and paste it after
another block. Change the text fields. Keep the comma after the closing brace.

REMOVE AN ENTRY
Delete its entire { ... }, block. For experience, include its bullets list.

CHANGE THE ORDER
Move a complete block up or down within its list.

CHANGE A PROJECT COVER
Put your new image in assets/. In content.js search for CHANGE COVER IMAGE.
Change image to your new path, such as assets/my-project.jpg. Update imageAlt
with a short description of the image.

EDIT EXPERIENCE BULLETS
Add or delete quoted lines inside bullets: [ ... ]. Keep commas between lines.

ABOUT ME
Edit the two paragraphs in the about section of index.html.

The layout handles additional entries automatically. site.js renders the lists;
you should not need to edit it. Upload all files together to update a hosted site.

THEMES AND STATUS
Use the Light / Dark / Blue buttons at the top. Light is the default on page load.
Edit the status subtitle in index.html beside EDIT CURRENT STATUS HERE.
Theme colors are grouped under THEME COLORS in index.html.


RESUME
The top Resume link opens assets/Arnav-Saraf-Resume.pdf. To update it, replace
that PDF with your new resume using the same filename.
